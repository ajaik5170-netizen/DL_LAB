# Experiment 2 - Comparative Study of Activation Functions and Optimization Algorithms in Deep Learning

## Aim

To analyze the impact of different activation functions and optimization algorithms on the performance of Artificial Neural Networks (ANNs) and to learn best practices for managing deep learning experiments using cloud-based tools and version control.

## Activation Functions

- Sigmoid
- Tanh
- ReLU

## Optimization Algorithms

- SGD
- Momentum
- RMSProp
- Adam

## Dataset

MNIST handwritten digit dataset.

## Tools Used

- Python
- TensorFlow
- Google Colab
- GitHub
- Matplotlib

## Tasks

### Task A
Visualization and comparison of Sigmoid, Tanh and ReLU activation functions.

### Task B
Performance comparison of ANN models using different activation functions.

### Task C
Comparison of SGD, Momentum, RMSProp and Adam optimization algorithms.

### Task D
Experiment management using Google Colab, Google Drive and GitHub.

## Results

The experiment compares activation functions using training accuracy, validation accuracy, training loss and validation loss.

The optimization algorithms are compared using training loss, validation loss, convergence speed, training accuracy and validation accuracy.
